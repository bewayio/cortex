# Module: shell

## Purpose

Window chrome and workbench layout: title bar, activity bar, sidebar, panes, status bar, persisted UI prefs.

## Boundaries

- Owns: layout state and prefs in `localStorage` (`bcode.sidebarWidth`, `terminalHeight`, `terminalWidth`, window size and position); `terminalDock` (`planned`: removed — see Notes, dock becomes per-terminal-tab, owned by `terminal`)
- Owns: language preference (`bcode.language`) and the i18n infrastructure (`frontend/src/i18n.ts`, `frontend/src/locales/`) consumed by every other module's components — ver Notes 2026-10-12.
- Does NOT own: business data of other modules

## Public Interface

| Method | Input | Output | Description |
|--------|-------|--------|-------------|
| Wails runtime (frontend) | WindowToggleMaximise, size and position | none | Window control from `App.tsx` |
| Window options (`main.go`, `window_options.go`) | Title, size, min size, background, `Frameless` per OS, `mac.TitleBarHiddenInset` | none | Native window setup |
| Menu bar | `TitleBar.tsx` | menus **Terminal**, **Chats com IA** (`MenuDropdown.tsx`, dropdown + submenu genérico), e o botão direto de **Configurações** (`SettingsModal.tsx`) | Não é um menu nativo do SO — ver Notes 2026-10-12 e 2026-10-18 |

- **Corrigido 2026-10-13, pedido do usuário — janela abria com uma engrenagem genérica em vez do novo logo, no Linux.** Causa raiz: `build/appicon.png` só é usado pelo `wails build` pra gerar os ícones de **empacotamento** (AppImage, `.icns` do macOS, `.ico` do Windows) — a janela GTK rodando de verdade no Linux não deriva o ícone dele sozinha. Precisa de `options.App.Linux.Icon` (`[]byte` de um PNG), que `main.go` nunca setava — sem isso, GTK cai no ícone genérico do ambiente de desktop (lido pelo usuário como "uma engrenagem"). Fix: `main.go` ganhou `//go:embed build/appicon.png` (`var icon []byte`) e `Linux: &linux.Options{Icon: icon}` em `wails.Run`. macOS/Windows não precisavam desse fix — o `.icns`/`.ico` já são embutidos no binário/bundle no momento do `wails build`, caminho diferente do GTK. `wails build` reconstruído e confirmado limpo depois do fix.
